# Chorus

Chorus turns a Mac into an isolated GitHub Actions runner for Xcode
builds: one fresh macOS VM per job, its contents declared in your
repository, its network filtered on the host.

This repository is Chorus's public home: the website at
[chorus.bmorton.dev](https://chorus.bmorton.dev), the downloads on the
[Releases](https://github.com/bmorton/ChorusApp/releases) page, and the
place to [open an issue](https://github.com/bmorton/ChorusApp/issues).
The app's source is not here.

Chorus is in beta.
